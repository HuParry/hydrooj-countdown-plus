# hydrooj-countdown-plus

为 Hydro OJ 首页添加倒计时，在 `/countdown` 页面直接管理。

## 安装

以下命令均使用运行 Hydro 的用户执行：

```sh
yarn global add hydrooj-countdown-plus
hydrooj addon add hydrooj-countdown-plus
pm2 restart hydrooj
```

如果 Hydro 使用其他方式运行，最后一步改为重启对应服务。

## 更新

重新执行安装命令即可更新插件，然后重启 Hydro。

## 使用

1. 使用系统管理员或主站管理员账号登录，打开 `你的 OJ 地址/countdown`，也可以从首页倒计时的“管理”或主站域管理中的“倒计时管理”进入。
2. 填写首页倒计时标题和最多显示条数。
3. 在 YAML 编辑框中修改倒计时，或将 AI 生成的新条目追加到已有内容末尾。
4. 点击“保存设置”，成功后自动返回首页。首次保存会自动显示倒计时，无需修改主页配置。

首页优先显示日期最近的条目，已过期条目自动隐藏。天数按北京时间计算：今天为 0 天，明天为 1 天。配置对全站首页生效，系统管理员和主站拥有“编辑域设置”权限的管理员可以编辑。

如果之前已在主页配置中填写倒计时，首次打开管理页面会自动读取，确认后保存即可。

## 用 AI 批量整理

1. 在管理页点击“复制提示词”，发送给支持联网查询的 AI；可以按需修改查询时间和赛事范围。
2. 将 AI 回答中的 YAML 列表追加粘贴到编辑框末尾，也支持粘贴带代码块标记的完整内容。
3. 核对日期及官方来源，点击“保存设置”。名称和日期完全相同的条目会自动去重。

提示词会收录官方已公布日期的暂定日程，包括标注“拟”“草案”“Tentative”的赛程。优先使用正式比赛日；若官方只公布赛期范围，则使用开始日期，并在名称后注明“（赛期开始）”。确实没有公布日期或已明确取消的赛事才不收录；延期后尚无新日期的赛事也会暂时排除。

编辑格式如下，示例不代表真实赛程：

```yaml
- name: "示例赛事 A"
  date: "2027-01-01"
- name: "示例赛事 B"
  date: "2027-02-01"
  source: "https://example.com/official-notice"
```

`name` 为名称，`date` 为正式比赛日或已注明的赛期开始日期，`source` 为可选的官方来源链接。每条从新的一行 `- name:` 开始，保留缩进。

保存使用编辑框中的全部内容；追加新条目时请保留原文。要删除某条，移除对应内容后保存；清空后保存会移除全部条目。格式或日期有误时，原有设置不会改变，页面也会保留你的输入。

## 修改提示词

直接编辑插件目录中的 `prompt.txt`，保存后刷新 `/countdown` 即可读取新内容，无需重启。文件中的 `{{today}}` 会自动替换为当天的北京时间日期。

## 查询比赛时间

管理页面提供以下官方入口，查询提示词也会引导 AI 核实这些来源：

- [ICPC 北京总部 · 赛事信息](https://icpc.pku.edu.cn/ssxx/index.htm)：查看亚洲 EC 区域赛汇总和各赛站信息。
- [CCPC 官网 · 赛事安排](https://ccpc.io/event)：查看各场比赛安排和赛站通知。

请区分报到、热身赛和正式赛日期，以各赛站最新通知为准。
