请联网查询并整理适合放在 OJ 首页的 ICPC、CCPC 赛事倒计时。

查询范围：从北京时间 {{today}} 起的未来 12 个月，ICPC 亚洲 EC 区域赛及 EC Final、CCPC 分站赛及总决赛。不要包含校赛、训练赛或网络选拔赛。

信息核实要求：
1. 优先查询官方入口及其链接的赛站通知、邀请函和承办高校公告：
   ICPC：https://icpc.pku.edu.cn/ssxx/index.htm
   CCPC：https://ccpc.io/event
2. 以最新公布的日程为准，尽量采用正式比赛的具体日期，不要把报名截止日当成比赛日期。
3. 这是日常赛程倒计时，不要求赛期已经最终确认。只要官方公布了具体日期或明确的日期范围，就应正常收录；即使日程标注“暂定”“拟”“草案”“Tentative”“Draft”，也不要因此排除或仅写成注释。不要额外要求主办方承诺比赛一定举行。
4. 日期选择：优先采用日程中列出的正式比赛日；若没有单列正式赛日期，但已公布连续赛期（例如某月某日至某日），则采用赛期的开始日期，并在 name 末尾加“（赛期开始）”，在 YAML 注释中说明原日期范围及取值依据。这是按已公布赛期设置倒计时，不需要猜测正式比赛具体在哪一天。
5. 只有确实没有公布具体日期或明确日期范围（例如仅说某月举办、日期待定），或已明确取消、已宣布延期且没有新日期的赛事才不收录。不要因为赛程尚未最终确定就省略已经有日期的场次。
6. 不要根据往年日期推算，不要虚构来源或日期。若无法联网查询，请直接说明无法查询，不要编造列表。
7. 查询时实际查看包含该比赛日程的官方通知、赛事汇总页面或邀请函，也可以查看 PDF；官方汇总中的暂定赛期也可以作为依据，不必等到正式邀请函发布。输出中无需附带来源链接。
8. 名称包含赛季年份、ICPC 或 CCPC 和赛站名，跨年赛事区分赛季与实际比赛日期。同一赛事只保留一条，按日期从近到远排序。

输出要求：
- 只输出一个 YAML 代码块，块外不写说明，不使用 Markdown 表格。
- 内容将被追加到已有 YAML 列表末尾，所以直接从“- name:”开始；每条仅包含 name、date 两个字段，不要添加其他字段或外层结构，也不要使用 --- 文档分隔符。
- name 是赛事名称；date 按上述规则选择正式比赛日期或已公布赛期的开始日期，严格使用 YYYY-MM-DD 格式并加引号。
- 所有字段值均使用 YAML 双引号字符串，特殊字符按 YAML 规则转义。
- 标注“拟”“暂定”“草案”“Tentative”的已公布赛期必须生成正常列表条目，可以附加 YAML 注释说明，但不能只放在“未收录”注释中。
- 只有没有公布具体日期或明确日期范围、明确取消、或延期后没有新日期的赛事，才在代码块末尾用 YAML 注释列出未收录原因。
- 若没有任何已公布日期的可收录赛事，只在代码块内用 YAML 注释说明，不生成空列表 [] 或占位条目。

格式示例（仅展示字段，不代表真实赛事，请替换为核实后的内容）：

  date: "YYYY-MM-DD"
